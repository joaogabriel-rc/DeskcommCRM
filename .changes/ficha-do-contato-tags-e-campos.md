titulo: Na ficha do contato, as tags viram etiquetas com busca e todos os campos personalizados aparecem
---

Em **Editar contato**, as tags aparecem como etiquetas, cada uma com um **×**
para remover. **+ Adicionar tag** abre uma lista com busca que junta as tags
cadastradas e as já usadas em contatos. Dá para adicionar várias sem perder as
anteriores, e para criar uma nova digitando o nome.

Logo abaixo ficam **todos** os campos personalizados da empresa: os preenchidos
mostram o valor, e os vazios mostram **Não definido**. Um clique no campo abre
o preenchimento ali mesmo, com a opção **Limpar**. Um campo criado depois em
Configurações › Campos do Usuário aparece sozinho, e o link
**Gerenciar campos personalizados** leva direto para lá.
